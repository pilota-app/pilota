# Instalar Pilota

1. Abre la página de [versiones](https://github.com/pilota-app/pilota/releases/latest).
2. Descarga el archivo de tu sistema (en Mac, el `.zip`).
3. Abre el archivo descargado.
4. La primera vez, si el sistema avisa que la app no está firmada, ábrela desde Ajustes del Sistema → Privacidad y seguridad →
   «Abrir igualmente».

Las versiones siguientes llegan dentro de la app: no tienes que descargar nada de nuevo.
